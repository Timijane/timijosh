Build your course lessons

Think of a course as a book. Chapters organise the topics, and lessons contain what students will read, watch or listen to.

Simple guide: Add a chapter (for example, “Introduction”), then add lessons under it. Each lesson can contain written notes, a YouTube link, an uploaded video, images, audio/voice notes and downloadable files. You can leave any content type empty if you do not need it.
